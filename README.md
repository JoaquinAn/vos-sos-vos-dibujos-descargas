# Biblioteca Vos Sos Vos

Acá se publica el programa. **Para instalarlo**: abrí [la última versión](https://github.com/JoaquinAn/vos-sos-vos-dibujos-descargas/releases/latest), bajá el archivo `...-windows.zip` y seguí estos pasos:

```
BIBLIOTECA VOS SOS VOS · Biblioteca de dibujos
==============================================

Guarda dibujos separados uno por uno y en vector (PDF y SVG), y sirve para combinarlos en
diseños nuevos. Funciona en tu computadora y no manda nada a internet.

INSTALAR
--------
1. Descomprimí el .zip en una carpeta que no vayas a borrar, por ejemplo Documentos
   (clic derecho → Extraer todo).
2. Abrí la carpeta "Biblioteca Vos Sos Vos" y hacé doble clic en "Biblioteca Vos Sos Vos.exe".
3. La primera vez, Windows puede mostrar "Windows protegió su PC". Pasa porque el programa no
   está firmado. Tocá "Más información" y después "Ejecutar de todas formas".
4. Se abre el navegador con la biblioteca. En el escritorio queda un acceso directo para las
   próximas veces.

USAR
----
- La biblioteca se abre en el navegador. No hace falta internet.
- Tus dibujos se guardan en  Documentos\Biblioteca Vos Sos Vos.
  Si borrás o actualizás el programa, tus dibujos siguen ahí.
- Para cerrar: menú "Más" (arriba a la derecha) → "Cerrar la biblioteca". Si cerrás la pestaña
  sin más, el programa se cierra solo a los 20 minutos.

COPIAS Y PASAR DIBUJOS
----------------------
- Menú "Más" → "Exportar una copia": baja toda la biblioteca en un .zip. Guardalo en un pendrive
  o en la nube de vez en cuando.
- Menú "Más" → "Importar una biblioteca": abre un .zip exportado (tuyo o de otra persona).
  Reemplaza la biblioteca abierta, pero no borra nada: la anterior queda guardada en
  Documentos\Biblioteca Vos Sos Vos\anteriores.
- Además, el programa guarda solo copias del índice en  biblioteca\_copias.

ACTUALIZAR A UNA VERSIÓN NUEVA
------------------------------
Es automático: cuando hay una versión nueva, aparece un aviso arriba de la biblioteca. Tocá
"Ver y actualizar" y después "Actualizar ahora". El programa baja la versión nueva, se cierra un
momento y se vuelve a abrir solo. Tus dibujos no se tocan.
También podés fijarte vos: menú "Más" → "Buscar actualizaciones" (hace falta internet).

Si alguna vez no funciona: cerrá la biblioteca, bajá la última versión de
https://github.com/JoaquinAn/vos-sos-vos-dibujos-descargas/releases/latest
y descomprimila en el mismo lugar que la anterior, reemplazándola.

SI ALGO FALLA
-------------
En  Documentos\Biblioteca Vos Sos Vos\registro.txt  queda anotado lo que pasó.
Mandale ese archivo a quien te pasó el programa.

```
